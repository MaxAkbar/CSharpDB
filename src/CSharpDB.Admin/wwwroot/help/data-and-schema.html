Data and schema

Browse Data and Manage Schema

Open database objects from Object Explorer to inspect records, edit values, create schema objects, and verify database structure.

Tables and Views

Click a table or view to open a data tab. The grid supports paging, sorting, filtering, selection, and inline edits when the source is writable.

The data browser shows row values, column filters, sort state, and pending edits.

  • Use column filters to narrow the visible rows.
  • Click column headers to sort ascending or descending.
  • Use Add Row, Delete Rows, Save, and Discard for editable tables.
  • Use page size and pager controls for large tables.

System Catalog and Internal Storage

System Catalog contains the supported read-only sys.* views for tables, columns, relationships, constraints, functions, temporary objects, statistics, and feature metadata. Open an entry to inspect its current rows with the suggested query.

Internal Storage shows the physical tables maintained by CSharpDB and Studio features. These backing tables are shown for troubleshooting and inventory only. Select one to open its filtered sys.internal_tables record; use the logical replacement shown beside it for normal work.

Backing tableUse instead
__data_model_diagramssys.diagrams and the Data Model workspace
__external_tablessys.external_tables and External Tables
__saved_queriessys.saved_queries and saved queries
_col_*The corresponding collection in Object Explorer
Do not treat backing tables as application tables. Their shape and lifecycle belong to the owning feature. Use the listed logical catalog or workspace so validation and metadata stay consistent.

Collections

Collections contain JSON documents keyed by document id. Collection tabs show document keys, JSON kind, compact previews, and a formatted JSON detail panel.

  • Open existing collections from Object Explorer.
  • Create documents with a nonblank key and valid JSON.
  • Save writes through the collection client API.
  • Delete removes selected documents after confirmation.

Data Modeler

The Data Model workspace starts as a curated canvas. Open Sources, search for a table, and choose Add for that table only or the relationship action to add it with its immediate parent and child tables. Load All remains available when you need the complete schema.

ControlDescription
Auto ArrangePlaces referenced tables to the left of dependent tables while preserving custom connector bends.
Tidy ModelResets custom connector routes, switches tables to Keys First, arranges the complete graph, and fits it into the canvas. It asks for confirmation when custom routes exist.
Fit ModelCenters and scales the visible tables and connectors without changing their saved positions.
Keys FirstShows primary keys, foreign keys, and columns used by visible relationships.
Expand All / Collapse AllShows every column or table headers only. Each table also has its own detail control.
Pan and zoomDrag the canvas background to pan and use the mouse wheel to zoom around the pointer.
DetailsOpens or closes the model inspector without reducing the normal canvas width.

Relationship lines use crow's-foot markers: the referenced end is one or optional-one according to child-column nullability; the child end is many unless that foreign-key column is uniquely constrained. Physical, pending, and archive relationships retain separate solid, dotted, and dashed styles. Select a table to emphasize its immediate neighborhood, or select a relationship to highlight both participating columns and display its name and column mapping. Click empty canvas space or press Escape to clear the selection.

Arrange connector bends

Select a relationship to show its bend handles and segment grips. Drag a bend to move its routing guide, or drag a segment grip sideways to introduce a right-angle detour. Double-clicking a segment adds a bend at that point. The Connector route section in Details provides Add Bend, Remove Bend, and Reset to Automatic. Add Bend focuses a new guide on the longest segment so you can move it.

With a bend focused, use arrow keys to move it by 8 canvas units, or Shift+Arrow for 24 units. Enter on a segment grip creates a bend. Delete or Backspace removes the focused bend, never the foreign key. Removing the last bend restores automatic routing. Escape cancels an active drag; otherwise it clears selection.

Table positions, custom bend coordinates, attachment sides, and the viewport are saved with the diagram. Bend edits save when released, and are also included in explicit Save. Reopening or refreshing preserves these positions. Moving a table keeps its connector guides fixed while the endpoint legs follow the participating columns. If a table covers a saved bend, a safe automatic route is shown temporarily; the saved guide is retained. Move the table away or reset the route in Details.

Know which action changes what. Moving or resetting connectors changes only the diagram layout. Removing a table only removes it and its connectors from the current canvas. Deleting a diagram removes the saved layout record. Applying staged changes executes the schema operations shown in the pending-change preview.

Query Editor

Use query tabs for ad hoc SQL, saved queries, query plans, table stats, column stats, and result review.

ActionDescription
RunExecutes SQL and shows results, row count, and elapsed time.
EstimateRuns EXPLAIN ESTIMATE FOR to show query-estimation inputs and planner decisions without executing the target query.
AnalyzeRuns ANALYZE to collect persisted table, column, histogram, and index-prefix statistics for the query planner.
FormatReformats SQL for readability.
SaveStores reusable SQL in the saved query catalog.
