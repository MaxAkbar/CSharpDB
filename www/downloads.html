Build the base CLI from source

From a repository checkout, use the .NET 10 SDK. This builds the base CLI, not the optional Access, SQL Server, or MySQL worker layout.

dotnet publish src/CSharpDB.Cli -c Release -o ./publish

The output requires .NET 10 Runtime. For the complete migration archive build process, see the migration packaging instructions.

JavaScript / TypeScript: build the client from source

The Node client is available in the repository, but there is currently no published csharpdb npm package. Use a source build instead. The wrapper declares Node.js 18 or newer; use a maintained Node.js release.

For a build matching the downloads above, start with a fresh v4.6.3 checkout, then install the build dependencies and compile the wrapper:

git clone --branch v4.6.3 --depth 1 https://github.com/MaxAkbar/CSharpDB.git CSharpDB-v4.6.3
cd CSharpDB-v4.6.3/clients/node
npm install
node node_modules/typescript/bin/tsc
npm pack

Install the resulting local .tgz into your own project with npm install /path/to/csharpdb-1.0.0.tgz. The wrapper has its own version; it is not the database release version.

Download the matching native library above. Set CSHARPDB_NATIVE_PATH to its absolute path, or put the library in your application's native/ directory. You do not need the .NET SDK when using a prebuilt native library.

Verify your download

Before extracting an archive, compare its SHA-256 hash with the matching checksum file linked above. Use the file from the same release: Admin, server, and migration archives have separate checksum lists.

Show checksum commands

Replace the example filename with the archive you downloaded. On Windows, use PowerShell:

Get-FileHash -Algorithm SHA256 -LiteralPath .\csharpdb-admin-desktop-v4.6.3-win-x64.zip

On Linux, place the checksum file next to the downloaded archive:

sha256sum --check --ignore-missing SHA256SUMS.txt

On macOS, compute the hash and compare it with the checksum list:

shasum -a 256 csharpdb-daemon-v4.6.3-osx-arm64.tar.gz

The native libraries and C header do not have a separate checksum-list asset in this release; do not use the server checksum list for those files. The package manifest describes the NuGet package set, not native-library checksums.
